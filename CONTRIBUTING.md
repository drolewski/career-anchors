# Contributing

Development and maintenance of this standalone project have ended. Its responsibilities now belong to [aptido.io](https://aptido.io).

The repository is retained as a historical reference. Feature requests and pull requests are not actively maintained or guaranteed a review. Corrections to the historical documentation may be considered at the owner's discretion.

For local exploration, follow the README, use synthetic data, and run `npm run lint`, `npm test`, and `npm run build`. Never include credentials, production configuration, database exports, or participant responses in an issue or change.

This repository has no open-source license; ask the owner before reusing or redistributing its contents.
